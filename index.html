Research directions

Asynchronous quantum error correction

When entanglement links become ready at different times, can available error checks proceed without waiting for an entire measurement round to synchronize? I study how code structure, measurement schedules, and decoding can account for link availability and accumulated memory noise, with the goal of protecting quantum information throughout execution while preserving fault tolerance.

Hybrid quantum repeater architectures

With Filip Rozpędek and Stav Haldar, I study fault-tolerant entanglement distribution in networks that mix many simple nodes with a sparse set of hybrid nodes. In our hardware model, simple nodes use highly multiplexed, shorter-lived memories (e.g., diamond color centers or atomic-frequency-comb memories); hybrid nodes add longer-lived, lower-error memories (e.g., trapped ions or neutral atoms) for storage and local error correction. We ask when the mix outperforms a uniform network, how much higher-quality hardware is needed, and where it should go.

Device geometry and correlated noise

I study how electrode geometry shapes electric-field noise and spatial correlations in ion traps, using Green-function models and numerical geometry diagnostics.
